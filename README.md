### 🌱 最近在折腾 / Recently tinkering with

- 🎛️ 嵌入式固件：ESP-IDF / FreeRTOS / C，写写驱动调调总线
- 🔌 硬件：原理图和 PCB Layout，打样回来焊焊烤烤调调烧烧[doge]
- 🖨️ 3D 打印：搭过好几个 FDM 打印机架构，Voron / Marlin 相关的项目，最近在搞多轴 CNC 和 OpenPNP，但业余时间比较少
- 🤖 机器人视觉：带队打过 RoboMaster；装甲板识别和 YOLO 都是很落后的方案了，眼球病变、铁路检测、军工的但都不适合开源，很久没再回视觉领域了，后续整理几个 Kaggle 的项目
- 🧠 AI 落地：LLM 网关、ESP32 上的语音助手，都是边看边做；做过好多 all-in-one，又觉得累赘，拆分成了好几个项目
- 🛠️ 一些给团队和自己用的小工具

也在一些团队/组织的项目里提交过代码，感谢一起干活的小伙伴们。
